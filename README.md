# Classification-d-images-avec-un-CNN-CIFAR-10-
Passage à la Computer Vision sur images couleur avec CIFAR-10 (60 000 images, 10 classes). Solution : Réseau de Neurones Convolutifs (CNN). Les blocs Conv2D et MaxPooling2D extraient automatiquement contours et textures, offrant une robustesse spatiale supérieure aux couches denses.
